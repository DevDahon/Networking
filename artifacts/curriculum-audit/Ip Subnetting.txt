IP Subnetting
Subnetting is the process of dividing a
large IP network into smaller, more
manageable sub-networks (subnets).
It helps optimize IP address usage,
reduce network congestion, and
improve security by controlling traffic
within each subnet.

PAGE 7
Without Subnetting
All devices share one large network, causing heavy broadcast traffic.
IP addresses are often wasted because the network cannot be divided
efficiently.
Network administration becomes complex and less efficient when all
devices are placed in a single large network.

PAGE 8
With Subnetting
The network is divided into smaller subnets, reducing congestion and
improving performance.
IP addresses are used more efficiently, matching the exact needs of
each subnet.
Security and management are easier since departments or groups can
be isolated and controlled.

IPv4 Address Structure
IPv4 addresses are 32-bit numbers divided into 4 octets (8 bits each).
Written in dotted decimal notation.
Each octet can have values from 0 to 255.

PAGE 11
Network vs. Host Portion
Network Portion
Identifies the subnet or “group” of devices.
Determined by the subnet mask.
Same for all devices within the same subnet.
Host Portion
Identifies the specific device (computer, printer, router) inside the subnet.
Varies for each device.
Must be unique within the subnet.

What Makes a Network?
IP Address - Unique identifier for each device in a network.
Subnet Mask - Defines which part of the IP is the network portion and
which part is the host portion.
Network Address - The first IP in a subnet, representing the subnet
itself.
Broadcast Address - The last IP in a subnet, used to send data to all
devices in that subnet.
Usable Host IP Addresses -  All IPs between the network and
broadcast addresses.

 CIDR Notation (Classless Inter-Domain Routing)
CIDR notation is a compact way of writing subnet masks.
Written as an IP address followed by a slash (/) and the number of
network bits. 
Show that the remaining bits (after the slash) are for hosts.
Unlike fixed classes (A, B, C), CIDR allows custom subnetting.
Example: 192.168.10.0/24
/24 → 24 bits are used for the network portion.
