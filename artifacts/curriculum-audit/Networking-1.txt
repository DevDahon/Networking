Course Description
Networking 1 examines the fundamental principles and practices of computer networking, including network components, architectures, topologies, communication models, protocols, and IP addressing. It emphasizes network connectivity, proper cabling procedures, network configuration, and basic network security.

Through lectures, demonstrations, guided laboratory exercises, and hands-on learning activities, students explore network types, OSI and TCP/IP models, Ethernet technologies, network media and connectors, IPv4 addressing and subnetting, peer-to-peer networking, wireless networking, and basic network security. Students use Cisco Packet Tracer, actual routers, Wi-Fi dongles, and appropriate networking tools to simulate, construct, configure, test, and troubleshoot basic wired and wireless networks.

At the end of the course, students are expected to identify, design, implement, configure, test, and troubleshoot basic computer networks using appropriate networking devices, tools, protocols, and configuration techniques.
