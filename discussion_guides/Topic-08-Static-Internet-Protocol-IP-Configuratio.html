Subnet Mask, Gateway, and DNS Roles

concept
📖 What to Read & Display on Screen

The subnet mask defines the local network boundary, the default gateway forwards remote traffic to the outside world, and Domain Name System (DNS) resolves hostnames to numeric Internet Protocol (IP) addresses.

  • 192.168.1.10/24 uses 24 network bits and 8 host bits; its mask is 255.255.255.0.
  • The default gateway is a local router used for destinations without a more specific route.
  • Domain Name System (DNS): maps names to records such as Internet Protocol (IP) addresses.

Two Ways to Assign an IP Address

concept
📖 What to Read & Display on Screen

  • Static: an administrator manually configures the address and related settings.
  • Dynamic: Dynamic Host Configuration Protocol (DHCP) supplies an address lease and configuration options.

What Is Static IP Configuration?

concept
📖 What to Read & Display on Screen

Static configuration assigns an interface’s address settings manually. A predictable address helps infrastructure and services remain locatable when settings are managed correctly.

  • Record address, mask, gateway, and Domain Name System (DNS) before changing anything. A Dynamic Host Configuration Protocol (DHCP) reservation is a different way to provide a stable address.
  • Choose a unique usable address in the intended subnet and coordinate it with the administrator’s addressing plan.
  • Avoid unmanaged overlap with Dynamic Host Configuration Protocol (DHCP) pools. Duplicate addresses cause conflicts even when each individual address is syntactically valid.

Four Key IPv4 Configuration Settings

concept
📖 What to Read & Display on Screen

A basic host configuration includes an address, subnet mask, default gateway, and name resolver. Each field has a separate purpose and must match the intended network.

  • Internet Protocol (IP) address: a unique usable address assigned to the interface.
  • Subnet mask: identifies which address bits describe the local network.
  • Default gateway: a local router for destinations needing a remote route.
  • Domain Name System (DNS) server: a resolver for names; not needed for numeric-IP local tests.

How Hosts Decide if a Peer is Local

concept
📖 What to Read & Display on Screen

Each host uses its own address and mask to decide whether a peer is local. A successful local round trip needs compatible decisions and a working link in both directions.

  • They can communicate by Internet Protocol (IP) on a correctly connected Local Area Network (LAN) without a default gateway.
  • 192.168.1.10/24 and 192.168.2.20/24 need appropriate routing between the two subnets.
  • Mismatched masks can make one host consider a destination local while the other sends through a gateway. Test both directions.

Example: two manually configured classroom computers

example
📖 What to Read & Display on Screen

Two hosts with unique usable addresses in the same subnet can communicate over a working local network. A default gateway is unnecessary for this numeric local exchange.

  • Both hosts calculate 192.168.1.0/24 as their local network, so this exchange does not require a router.
  • The addresses must be unique and the link and host policy must permit communication. A successful address calculation alone does not prove reachability.

Configuring Static IP in Windows

concept
📖 What to Read & Display on Screen

Windows adapter settings control an interface’s address and related options. Configuration must be verified through both inspection and an appropriate connectivity test.

  • Open Settings → Network & Internet → Advanced network settings → More network adapter options (or run ncpa.cpl).
  • Open the intended adapter’s Properties → Internet Protocol Version 4 (Transmission Control Protocol (TCP)/IPv4) → Properties. Enter the approved values, then confirm.
  • Use ipconfig /all and ping the peer’s numeric address. Record results; restore “Obtain an Internet Protocol (IP) address automatically” and automatic Domain Name System (DNS) if that was the original setup.

Windows Static Address Configuration Procedure

walkthrough
📖 What to Read & Display on Screen

Manual address configuration requires the intended adapter and a coordinated set of valid settings. Recording the original configuration supports verification and restoration after the change.

  • Record the original configuration and select the intended adapter. Open ncpa.cpl, adapter Properties, then Internet Protocol Version 4 (Transmission Control Protocol (TCP)/IPv4) Properties.
  • On an approved isolated Local Area Network (LAN), 192.168.1.10/24 and 192.168.1.20/24 are compatible local hosts. A gateway is unnecessary for a numeric local test.
  • Use ipconfig /all to inspect settings, then test the peer in both directions. If Internet Control Message Protocol (ICMP) is filtered, examine approved policy rather than disabling the firewall.
  • Changing the second host to 192.168.2.20/24 requires appropriate gateways and bidirectional routing for cross-subnet communication.
  • Restore the original approved Internet Protocol (IP)/Domain Name System (DNS) method after a physical demonstration; browser settings do not change the real Windows adapter.

Configuring a Static LAN Printer

application
📖 What to Read & Display on Screen

A classroom host can use the same router address for its gateway and forwarded name-resolution service, while a printer benefits from an address coordinated outside the dynamic Dynamic Host Configuration Protocol (DHCP) pool.

  • The host and gateway share a local subnet; the router may forward Domain Name System (DNS) requests.
  • The printer benefits from an address excluded from the Dynamic Host Configuration Protocol (DHCP) dynamic pool to prevent conflicts.
  • Verify numeric connectivity and service ports separately; a successful ping does not prove application reachability.
