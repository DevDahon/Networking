What Is a Computer Network?

concept
📖 What to Read & Display on Screen

A computer network is a system of two or more connected devices that exchange data and share resources. Wired or wireless links carry the data using agreed communication rules called protocols.

  • Connected devices: computers, phones, servers, and printers can all participate in a network; the devices do not have to be identical.
  • Communication: a device sends data through a connection, and another device receives and interprets it using compatible communication rules.
  • Shared access: connected users can exchange messages, use shared files, or send work to a network printer. A local network can provide these services without Internet access.

Basic Network Components

concept
📖 What to Read & Display on Screen

A network combines end devices, connecting devices, and links. These create or receive data, provide paths, and carry signals between devices.

  • End devices create or receive data: computers, phones, servers, and printers.
  • Connecting devices provide paths: a switch joins local wired devices, a wireless access point connects wireless devices, and a router joins networks.
  • Links carry signals: Ethernet cables, optical fiber, and wireless radio connect compatible interfaces.

Five Elements of Data Communication

concept
📖 What to Read & Display on Screen

Data communication involves a sender, receiver, message, medium, and protocol. Together, these explain who exchanges data, what travels, how it travels, and which rules make it understandable.

  • Sender: the device originating a message.
  • Receiver: the intended destination of the message.
  • Message: the data being exchanged.
  • Medium: the physical or wireless path carrying the message.
  • Protocol: rules for formatting, addressing, and exchanging the message. Both sides must support compatible rules.

Four network coverage types

concept
📖 What to Read & Display on Screen

Network coverage describes the geographic scope of connected devices and sites. Personal, local, metropolitan, and wide area networks differ in scope rather than following universal distance cutoffs.

  • Personal Area Network (PAN): devices around a person, such as a phone and Bluetooth headset.
  • Local Area Network (LAN): a room, building, or local campus network, including a wireless Local Area Network (LAN).
  • Metropolitan Area Network (MAN): interconnects sites across a metropolitan area.
  • Wide Area Network (WAN): spans wider regions, often using carrier links. The Internet interconnects many networks.

Two network service architectures

concept
📖 What to Read & Display on Screen

Network architecture describes which devices request and provide services. Peer-to-peer and client-server arrangements can both operate within the same geographic network type.

  • Peer-to-peer: peers can both request and provide resources, such as one Personal Computer (PC) sharing a folder with another.
  • Client-server: clients request services from dedicated service providers, such as a school file server.

Two link choices: wired and wireless

concept
📖 What to Read & Display on Screen

Wired links carry signals through a physical cable, while wireless links use radio. One network can combine both methods without changing its geographic classification.

  • Ethernet provides a cabled link with predictable interference characteristics and a physical port requirement.
  • Wi-Fi provides radio access and mobility; walls, interference, distance, and shared airtime affect performance.
💡 Brief Explanation After Reading (Teacher's Discussion Notes)

🌟 Real-World Analogy / Intuition

Discover everyday networking, classify network coverage and architectures, and follow a simple exchange between devices.

🗣️ How to Explain It (Talking Points)

  • Ethernet provides a cabled link with predictable interference characteristics and a physical port requirement.
  • Wi-Fi provides radio access and mobility; walls, interference, distance, and shared airtime affect performance.
  • Neither medium is automatically secure.
  • Use authentication, encryption, and appropriate access controls.
