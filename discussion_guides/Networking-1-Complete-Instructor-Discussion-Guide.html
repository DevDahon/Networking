What Is a Computer Network?

concept
📖 What to Read & Display on Screen

A computer network is a system of two or more connected devices that exchange data and share resources. Wired or wireless links carry the data using agreed communication rules called protocols.

  • Connected devices: computers, phones, servers, and printers can all participate in a network; the devices do not have to be identical.
  • Communication: a device sends data through a connection, and another device receives and interprets it using compatible communication rules.
  • Shared access: connected users can exchange messages, use shared files, or send work to a network printer. A local network can provide these services without Internet access.

concept
📖 What to Read & Display on Screen

Data communication involves a sender, receiver, message, medium, and protocol. Together, these explain who exchanges data, what travels, how it travels, and which rules make it understandable.

  • Message: the data being exchanged.
  • Medium: the physical or wireless path carrying the message.

concept
📖 What to Read & Display on Screen

Network coverage describes the geographic scope of connected devices and sites. Personal, local, metropolitan, and wide area networks differ in scope rather than following universal distance cutoffs.

Six network topologies

concept
📖 What to Read & Display on Screen

Star, bus, ring, mesh, tree, and hybrid networks use different connection patterns. Those patterns affect expansion, cost, available paths, and the impact of failures.

  • Star: endpoints connect to a central switch. A single endpoint cable failure usually isolates that endpoint.
  • Bus: a classic shared coaxial backbone requires correct termination. A backbone break disrupts the segment.
  • Ring: a classic single ring passes traffic along a closed path. A break disrupts this simple model; protected rings may recover.
  • Full mesh: every node connects directly to every other node; alternate paths can survive one link failure.
  • Tree: branches connect hierarchically. An upstream link failure isolates the subtree below it.
  • Hybrid: combines layouts, such as two stars joined by a backbone. The effect of a failure depends on where it occurs.

concept
📖 What to Read & Display on Screen

An Internet Protocol (IP) address is a unique logical Layer 3 numerical identifier assigned to every device on a network. While a physical Media Access Control (MAC) address identifies hardware on a single local cable, an IP address is hierarchical and location-based, enabling routers to direct data packets across interconnected local, enterprise, and global networks.

concept
📖 What to Read & Display on Screen

  • Why We Subtract Two (Total − 2): Because the Network ID (first) and Broadcast Internet Protocol (IP) (last) are reserved for network roles, usable host capacity is always Total IPs minus 2.

Classful History vs Modern Subnetting

concept
📖 What to Read & Display on Screen

Six Windows diagnostic commands

concept
📖 What to Read & Display on Screen

Diagnostic commands inspect configuration, reachability, name resolution, or neighbor information. Each answers a limited question rather than proving that the whole network works.

  • ipconfig: shows basic interface configuration; it does not prove reachability.
  • ipconfig /all: shows detail such as Domain Name System (DNS), Dynamic Host Configuration Protocol (DHCP) server, and leases; it does not prove reachability.
  • ping: tests Internet Control Message Protocol (ICMP) Echo behavior and round-trip time; a timeout can also mean filtering or packet loss.
  • tracert: provides TTL-based hop evidence; filtered probes can produce gaps.
  • nslookup: queries Domain Name System (DNS); success does not prove the destination service works.
  • arp -a: lists cached Internet Protocol version 4 (IPv4) neighbor mappings, not every device on the Local Area Network (LAN).
