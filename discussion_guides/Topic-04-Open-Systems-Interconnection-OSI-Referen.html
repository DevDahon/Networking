Seven OSI layer responsibilities

concept
📖 What to Read & Display on Screen

The Open Systems Interconnection model names seven responsibilities involved in communication. A classic memory aid from Layer 1 to 7 is "Please Do Not Throw Sausage Pizza Away".

  • Application: Network services and protocols used directly by end-user applications.
  • Presentation: Data formatting, character encoding, translation, and encryption.
  • Session: Dialog management, establishing, maintaining, and synchronizing communication sessions.
  • Transport: End-to-end communication, segmentation, flow control, and error recovery.
  • Network: Logical addressing and path determination (routing) across interconnected networks.
  • Data Link: Physical addressing, framing, media access, and local hop delivery.
  • Physical: Transmission and reception of raw binary bitstreams over a physical medium.

What Is Encapsulation?

concept
📖 What to Read & Display on Screen

Encapsulation adds control information around application data for transport, network, and link delivery. The receiver interprets the corresponding headers and framing to recover the data.

  • Application data is carried in a Transmission Control Protocol (TCP) segment or User Datagram Protocol (UDP) datagram, then an Internet Protocol (IP) packet, then a link-layer frame. Physical signals carry the frame bits.
  • The receiver interprets and removes the relevant headers. Ethernet also uses a trailer for error detection.

Two transport services: TCP and UDP

concept
📖 What to Read & Display on Screen

Transmission Control Protocol supplies an ordered reliable byte stream, while User Datagram Protocol supplies independent datagrams. Applications choose the behavior their communication needs rather than assuming one transport is always better.

  • Transmission Control Protocol (TCP): an ordered reliable byte stream with sequence numbers, acknowledgments, and retransmission.
  • User Datagram Protocol (UDP): datagrams without built-in delivery or ordering guarantees; applications may add reliability.

Four layers in the TCP/IP model

concept
📖 What to Read & Display on Screen

The common Transmission Control Protocol (TCP)/Internet Protocol (IP) model groups communication into Application, Transport, Internet, and Link. These groups connect application services to the delivery and transmission functions underneath them.

  • Application: application protocols plus representation and dialog functions.
  • Transport: process-to-process services, including Transmission Control Protocol (TCP) and User Datagram Protocol (UDP).
  • Internet: Internet Protocol (IP) logical addressing and forwarding across networks.
  • Link: local framing, media access, and physical transmission.
💡 Brief Explanation After Reading (Teacher's Discussion Notes)

🌟 Real-World Analogy / Intuition

A user sends a message; the exchange depends on signals, framing, routing, transport, and an available application service.

🗣️ How to Explain It (Talking Points)

  • Application: application protocols plus representation and dialog functions.
  • Transport: process-to-process services, including TCP and UDP.
  • Internet: IP logical addressing and forwarding across networks.
  • Link: local framing, media access, and physical transmission.
