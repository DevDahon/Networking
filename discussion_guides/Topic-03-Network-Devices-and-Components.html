Nine common network devices

concept
📖 What to Read & Display on Screen

Network devices connect hosts, carry signals, forward data, or enforce access rules. A single product can combine several functions, so its behavior matters more than its shape.

  • Network Interface Card (NIC): provides a host network interface.
  • Hub: repeats incoming bits to other ports without learning Media Access Control (MAC) destinations.
  • Switch: learns Media Access Control (MAC) information and forwards local-link frames.
  • Router: forwards Internet Protocol (IP) packets between networks using routes.
  • Modem: adapts signals for a provider access technology.
  • Wireless access point: bridges Wi-Fi stations onto a Local Area Network (LAN).
  • Repeater: regenerates or retransmits signals.
  • Bridge: joins link-layer segments; a switch is a multiport bridge.
  • Firewall: permits or blocks traffic according to policy.

Network Interface Card (NIC)

concept
📖 What to Read & Display on Screen

A Network Interface Card provides the physical connection and hardware Media Access Control (MAC) address that allows a computer to send and receive frames on a local link.

  • Physical connection: Houses the physical port (such as Registered Jack 45 (RJ45) or Wi-Fi radio) and controller chip for host communication.
  • Unique hardware identity: Permanently assigned a factory-burned 48-bit Media Access Control (MAC) address for local link delivery.
  • Data transmission: Converts host memory data into electrical or radio bitstreams, framing data with Media Access Control (MAC) addresses and CRC checksums.

Network Hub

concept
📖 What to Read & Display on Screen

A network hub is a legacy Layer 1 multiport repeater that blindly broadcasts incoming electrical signals out all other ports, creating a shared collision domain.

  • Multiport repeater: Connects multiple twisted-pair Ethernet cables in a single shared electrical bus.
  • No address awareness: Operates purely at Layer 1; it cannot read Media Access Control (MAC) addresses, Internet Protocol (IP) packets, or inspect frames.
  • Broadcast behavior: Any electrical bit received on one port is broadcast out to every other port, creating a single shared collision domain.

Network Switch

concept
📖 What to Read & Display on Screen

A network switch is an intelligent Layer 2 device that learns Media Access Control (MAC) addresses on each port to forward frames directly to their intended destination.

  • Dedicated bandwidth: Connects local hosts with dedicated point-to-point links, eliminating collisions between ports.
  • Media Access Control (MAC) address table: Dynamically inspects the source MAC of incoming frames and maps each address to its incoming physical port.
  • Forwarding decision: When a frame arrives, the switch forwards known unicast directly to the target port; only unknown destinations are flooded.

Network Router

concept
📖 What to Read & Display on Screen

A router is a Layer 3 internetworking device that uses routing tables to forward Internet Protocol (IP) packets across different networks and broadcast domains.

  • Network boundary: Separates distinct broadcast domains and connects local subnets to WANs or the global Internet.
  • Routing table: Maintains a table of network destination prefixes, next-hop Internet Protocol (IP) addresses, and outgoing interfaces.
  • Packet forwarding: Reads destination Internet Protocol (IP) headers, decrements the Time to Live (TTL), determines the best path, rewrites the Layer 2 frame, and forwards.

Modem (Modulator-Demodulator)

concept
📖 What to Read & Display on Screen

A modem converts digital computer pulses into analog signals for provider transmission lines, adapting local Ethernet to external provider media.

  • Media adaptation: Bridges home or office Ethernet to provider infrastructures like telephone lines (Digital Subscriber Line (DSL)), cable (DOCSIS), or fiber (ONT).
  • Modulation & demodulation: Modulates outgoing digital square waves into analog carrier frequencies and demodulates incoming analog waves back to bits.
  • Signal conversion: Local Area Network (LAN) Ethernet packets enter the modem, are modulated onto high-frequency RF carriers over coaxial or copper cables, and reach the ISP headend.

Wireless Access Point (AP)

concept
📖 What to Read & Display on Screen

A wireless access point bridges radio frequency signals from Wi-Fi client stations onto a wired Ethernet local area network.

  • Radio transceiver: Transmits and receives radio waves across 2.4 GHz, 5 GHz, or 6 GHz frequency bands.
  • Layer 2 bridge: Bridges IEEE 802.11 wireless frames into IEEE 802.3 wired Ethernet frames without changing Internet Protocol (IP) addresses.
  • Client bridging: Broadcasts an Service Set Identifier (SSID) beacon, authenticates wireless client devices, and transparently forwards their traffic to the wired switch via PoE uplink.

Network Repeater

concept
📖 What to Read & Display on Screen

A repeater regenerates and retimes attenuated signals at the physical layer, extending the effective reach of a network cable or wireless link.

  • Overcoming attenuation: Counteracts signal loss and cable resistance that degrade data beyond standard maximum run lengths.
  • Signal regeneration: Rather than merely amplifying noise, a digital repeater reconstructs clean, full-voltage digital pulses.
  • Signal restoration: Listens on an input interface, cleans and retimes the incoming waveform, and retransmits it at full strength across the extended medium segment.

Network Bridge

concept
📖 What to Read & Display on Screen

A network bridge joins two physical Local Area Network (LAN) segments at Layer 2, filtering local traffic to isolate collisions while forwarding necessary inter-segment frames.

  • Traffic segmentation: Divides a busy network into two smaller collision domains while keeping them in the same subnet.
  • Filtering table: Maintains a list of Media Access Control (MAC) addresses on Segment A and Segment B to decide whether traffic needs to cross.
  • Frame filtering: If sender and receiver are on Segment A, the bridge filters (drops) the frame from crossing; if the target is on Segment B, it forwards it across.

Network Firewall

concept
📖 What to Read & Display on Screen

A firewall enforces security policies at network boundaries, inspecting packet headers and connection states to permit authorized traffic and block threats.

  • Security perimeter: Sits at network boundaries (e.g. between Local Area Network (LAN) and Internet) or as host software to defend against unauthorized access.
  • Inspection methods: Uses packet filtering (Internet Protocol (IP)/ports), stateful inspection (tracking active connections), or deep packet inspection (DPI).
  • Policy enforcement: Inspects packet headers against security rules; permitted traffic (e.g. outbound web) is passed, while unauthorized packets are dropped or rejected.

How Interfaces and Switches Connect Local Devices

concept
📖 What to Read & Display on Screen

A network interface lets a host send and receive data on a link. A switch connects local links and uses learned hardware addresses to forward Ethernet frames.

  • A hub repeats incoming bits out its other ports; it does not learn destination Media Access Control (MAC) addresses.
  • A switch learns source Media Access Control (MAC) addresses and forwards known unicast frames toward the learned destination port. Unknown destinations are flooded within the Virtual Local Area Network (VLAN).
  • A bridge joins Local Area Network (LAN) segments at layer 2. A switch is effectively a multiport bridge.

Routers, Access Points, and Modems

concept
📖 What to Read & Display on Screen

A router forwards packets between networks, while an access point connects wireless devices to a local network. A modem or optical terminal supports the provider’s access technology.

VLAN Concepts and Routing Principles

concept
📖 What to Read & Display on Screen

Virtual LANs divide a single physical switch into isolated logical broadcast domains, while routers connect them using static or dynamic routing rules.

  • Virtual Local Area Network (LAN) (Virtual Local Area Network (VLAN)): Divides one physical switch into multiple separate logical broadcast domains (e.g., VLAN 10 for Students, VLAN 20 for Faculty).
  • Broadcast Isolation: Broadcast traffic (such as Address Resolution Protocol (ARP) and Dynamic Host Configuration Protocol (DHCP)) stays confined inside its assigned Virtual Local Area Network (VLAN), boosting performance and security.
  • Inter-VLAN Routing: Because devices in different VLANs cannot communicate directly, all inter-VLAN traffic must pass through a router or Layer 3 switch.
  • Static Routing: A network administrator manually enters fixed destination routes into the router table (simple, predictable, low overhead for small networks).
  • Dynamic Routing: Routers automatically discover paths and exchange network routes using protocols like OSPF and RIP (automatically updates if a link fails).

Device Roles Along a Network Path

walkthrough
📖 What to Read & Display on Screen

A request can pass through several devices, each performing a different job. Interfaces, switching, routing, and provider access work together without being interchangeable functions.

  • The Personal Computer (PC) Network Interface Card (NIC) sends a frame through an Ethernet port to a switch. Link indicators show link detection, not proof of Internet Protocol (IP) or Internet access.
  • The switch forwards a known local unicast toward its learned destination port. A hub would repeat incoming bits to other ports.
  • For a remote Internet Protocol (IP) network, a router selects the next hop. Its Local Area Network (LAN) and Wide Area Network (WAN) interfaces face different network roles.
  • A home gateway may also contain an Access Point (AP), switch, Dynamic Host Configuration Protocol (DHCP) service, Network Address Translation (NAT), and firewall. A modem or optical terminal serves the provider access technology.

Expected Answer / Guidance: Encourages learners to explain the functional role and real-world impact of device roles along a network path.

Key Takeaway: A request can pass through several devices, each performing a different job. Interfaces, switching, routing, and provider access work together without being interchangeable functions.
